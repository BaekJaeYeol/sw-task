# 소프트웨어공학 과제

## 과제 1: 프로젝트 관리

**주제: 소형 온실 자동 제어기 개발**

[과제 1 전체 문서 보기](coursework/software-engineering/assignment-01-project-management.md)

- 대상 제어기 선택
- 프로젝트 범위 정의
- 시스템 문맥도 및 이해관계자 분석
- 제약사항 조사
- 프로젝트 규모 산정
- 주요 업무 구분 및 WBS 연계

2026년 10월 12일 부품 사양과 표시 가격을 조사하여 4단계를 보완했습니다. 가격 부분 합계는 70,700원이며 팬·전원·조작부·배송비 등은 미견적입니다. 실제 구매·구현·시험은 진행하지 않았습니다.

인원·기간·예산 상한·성능 목표는 계획 가정이며, 제출 전 실제 조건과 학번을 확인해야 합니다.
